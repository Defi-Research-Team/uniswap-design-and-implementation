## 通用规范

- 章节内容的组织顺序和逻辑关系是线性递进的，不存在前面依赖后面的内容，后面又依赖前面的内容这种循环依赖链条
- 删除重复或冗余表述，保持书籍内容精炼
- 英文语境中不能参杂汉语，统一英文表述，确保语法正确，用词准确规范
- 优化句式表达，确保语句通顺，逻辑顺畅
- Markdown 格式符合出版物级别的标准和规范
- 标点符号使用正确且统一，任何语境下均禁用破折号
- 标题准确反映章节内容，如果有更加符合章节内容的标题，优化之
- 章节之间无分隔线
- 用词准确规范，语句通顺连贯
- 如有重复冗余的地方，删除重复冗余，保持内容精练无重复
- 书籍内容无事实性错误，无前后差异甚至矛盾
- 书籍内容连贯，结构、用词等一致，表述统一，符号统一，格式一致，公式、图的编号和引用都完全一致
- 术语定义不要使用列表形式，而是使用段落自然引出
- 图需要带编号和详细图注，保持 alt 文本精简，避免二者信息重复
- 行公式必须携带编号
- 总结不要用列表，而是用 1-2 个段落进行总结。每个段落几句精要的话，概括归纳本章节核心内容
- ❌不允许增加额外的内容
- ❌不允许删除非重复冗余的内容
- 🚫 不允许改变文章的整体结构

## 术语排版规范

- 术语必须是广泛接受或官方定义的。格式为斜体 _术语_。若术语前方不是文字（句首、标点后），无需前导空格；若前方是文字，需加一个前导空格，如 提供 _流动性_。
- 有对应英文时用 _术语（english term, 缩写）；缩写同样必须广泛接受/官方（如 CEX、DEX、CPMM、AMM、LP、IL），否则省略缩写写成_术语（english term）（如 _订单簿（Order book）、_做市商（Market Maker））。
- 中文语境的括号用全角 （），括号内的英文标点（逗号等）用半角 ,。仅在首次引入/定义处加斜体+英文，后续复述用纯文本。
