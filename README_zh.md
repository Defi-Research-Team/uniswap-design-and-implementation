## 本地编译与阅读

安装 [mdBook](https://rust-lang.github.io/mdBook/)：

```bash
cargo install mdbook
```

编译并启动本地服务：

```bash
# 中文版
mdbook serve zh --open

# 英文版
mdbook serve --open
```
